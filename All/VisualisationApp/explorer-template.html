How to read this view

Top bars show the number of sites supporting each interaction. Left bars show each site's interaction richness in the current view. Filled cells record observed interactions; an empty cell means not observed. Regional support always uses the full dataset, including when a species or site filter is active.

Removal previews one site at a time. Losing all recorded partners includes species disappearing from the interaction records; it does not establish biological extinction or independent species presence. Similarity order is average-linkage clustering of the full incidence matrix using Jaccard dissimilarity; it is not a statistical test.
